I'm not a very good programmer, but I love programming. I started with scripts on NT4 and never really stopped.

What I enjoy most is learning a new language and trying to recreate an application I like, just to see how it works on the inside.

For years I hardly finished anything. Life always got in the way, and I didn't mind: I have way too many hobbies and interests. Since AI came along, I actually get projects done.

Most of my code lives on my own Forgejo server at home, so it isn't public. A few things are on GitHub.

What I've been working on

  • Moonbound desktop QML, C++
    My Omarchy rice: a spellbook look for the whole desktop, with a matching theme and an animated book menu.
  • Enchanted edges C++23
    A Hyprland plugin that puts glowing particles around the focused window. My first native plugin.
  • Harpoon QML, JavaScript
    Bookmark up to 10 windows and jump to them from anywhere. Inspired by ThePrimeagen's Harpoon for Neovim.
  • Backdrop QML, Python
    Wallpapers per workspace or monitor, with timed rotation and animated transitions.
  • Keystrokes QML, JavaScript
    Shows the keys I press as keycaps on screen, for recordings and demos. A rewrite of my older Python version.
  • Neovim plugins Lua
    A Codex pane inside Neovim, and a notes panel under the file explorer.
  • BOOMDOCK AI TypeScript, Python
    My own app for talking to AI agents and running Codex or Claude Code in sandboxes, from my phone. Plus an MCP server that ties it to my projects, Forgejo and calendar.
  • Archimedes Rust
    A little owl that lives on my Hyprland desktop and flies between monitors. GTK4 and OpenGL.
  • GitHub publisher Python
    I develop in Forgejo and push a clean snapshot of a project to GitHub when I want to share it.
  • dots Bash
    A small tool to keep my dotfiles in git and sync them between my machines.
